# Migration certificate (idea 3, level B)

What the Chief sends in Telegram and the dashboard shows at `/certificado` at the end of the demo. Implemented by: Guilherme (chief and orchestrator). Design in `material/design/web.pen`, frame "Certificado de migração".

> **Implementation note (20/11):** the real certificate is generated in English and the summary is built from the measured fields; the AI does not write the certificate (`code/chefe/certificado.ts`). The template below is the original design.

## Data sources

Everything comes from files that already exist. **Nothing is written by hand or invented by the AI.**

| Field | Where it comes from |
|---|---|
| Identifier and time | Generated by the orchestrator at the end (`CERT-AAAAMMDD-HHMM`) |
| Migrated services | Output of the `migrador` (`analisar` + `migrarS3` + …) |
| Where each piece of data ended up | Instance region from the Leaseweb API (`GET /instances`) and the provider chosen by the decider |
| Objects and rows copied | Output of the `migrador` |
| Checksums before and after | Output of the `migrador` vs `exemplo-app/seed/esperado.json` |
| Tests before and after | `migrador/verificar.ts` |
| What the attacker found | `auditoria.jsonl`, attacker events |
| What the defence closed, who approved it, and when | `auditoria.jsonl`, defence events |
| Exposure time | Exposure clock (time the migration ended → time the close was confirmed) |
| Stored reversible actions | `auditoria.jsonl`, field `inverso` |

The AI may only write the "Summary" paragraph at the top, from this data, in at most 3 sentences.

## Template (Telegram text)

```
MIGRATION CERTIFICATE · {id}
{date} {time} · Leaseweb Public Cloud, {region}

SUMMARY
{3 sentences from the AI, based on the data below}

1. WHERE THE DATA IS
{for each service}
· {AWS service} → {destination} · {provider}, {country} · {self-hosted | managed}

2. PROOF NOTHING WAS LOST
· Files: {n} copied · checksum {match ✓ | mismatch ✗}
· Database: {n} rows in {t} tables · checksum {✓ | ✗}
· App tests: before {✓} · after {✓}

3. SECURITY AFTER THE MIGRATION
· Found: {n} issue(s), {severity}
· {for each issue} {service} port {p} open to the whole Internet → closed at {time}, approved by {who}
· Time exposed: {s} seconds
· Attacker confirmation: {can no longer reach it ✓}

4. HOW TO UNDO
· {n} actions stored with the inverse · undo: /undo {pedidoId}

No data left the EU. Generated automatically from the audit log.
```

## Rules

- If a field is missing, write "not measured". Never invent.
- If a checksum does not match, the certificate shows ✗ prominently and the Chief warns that the migration is not complete.
- It contains no secrets and no personal data from the app, only counts and hashes.
- For GDPR and NIS2 it serves as a record; it is not an official certification. Do not call it a "certification".
